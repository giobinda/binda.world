  1. 01

    EthiCook

    On Google Play

    Android app · Kotlin

    Scans barcodes and printed expiry dates in one go, reminds you before food goes off, and turns what's already in the cupboard into recipes. Private, mostly offline.

    Exists because the back of the fridge is where groceries go to become compost.

    • 200 recipes built in, ranked by what you have
    • PostgreSQL, BigQuery, Parquet/CSV/Iceberg via DuckDB
    • Multi-tenant, row filters that only ever narrow
    • Passkeys, SSO, and guest links that expire

    Coming soon to Google Play

    Android app · Kotlin

    A metronome that listens. A timing coach hears whether you're early or late, through the microphone or exactly over USB from an e-drum, with 26 step-by-step lessons from the first beat to full grooves.

  4. 04

    Attaché

    Beta · not independently audited

    Linux privacy tool · Rust

    An encrypted folder that asks which program may open your files. Every access gets an Allow once / Always allow / Deny prompt, keyed on the calling binary. The vault locks itself when idle, at logout and before suspend.

    Exists because a lock is nice, but a bouncer checks names.

    • Built on gocryptfs
    • Per-binary whitelist travels inside the vault
    • Exports to disc with the tools to open it

    Source Releases

  5. 05

    Inkswitch

    Tested on exactly one tablet

    Linux driver & settings app · Rust

    A replacement driver for XP-Pen drawing tablets, with profiles that switch by themselves depending on which application is in front: Krita, GIMP, Blender, anything.

    Exists because the vendor driver and I had creative differences.

  6. 06

    exfat-grow

    0.1.0 · back up first

    Linux disk utility · Python

    Grows an exFAT filesystem in place, without reformatting and without copying your data elsewhere first. A wizard asks before every step that writes anything.

    Exists because exfatprogs, parted and GParted all politely declined.

    • Single file, standard library only
    • Field-tested: 466 GiB → 954 GiB, data intact

    Source

  7. 07

    Grilled Phish

    In the lab · not released

    Browser extension · JavaScript

    Catches look-alike scam links, like paypa1.com, a Cyrillic pаypal.com or paypal.com.secure-verify.xyz. They get a red box, they don't open when clicked, and the warning highlights exactly which letter is lying to you.

    Exists because nobody should have to proofread a domain name before paying a bill.

    • All look-alike checks run on your computer
    • Recognises copies of the 100,000 most visited sites
    • Blocks websites registered in the last few days
    • Chrome, Edge, Brave and Firefox

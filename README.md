# binda.world

Personal portfolio site. Plain static HTML/CSS, served by GitHub Pages at https://binda.world
(`binda.online` redirects here).

- `index.html` — the page; projects are written inline.
- `styles.css` — all styling (light/dark via `prefers-color-scheme`).
- `CNAME` — the custom domain for GitHub Pages.

Preview locally: `python3 -m http.server` and open http://localhost:8000.
